# Firm payments documentation

[Open the requirement-by-requirement documentation](https://newdarwindev.github.io/firm-payments-docs/)

This repository hosts the public documentation generated by GitHub Actions in the private `newdarwindev/firm-payments` repository. It contains the original assignment recital, selected verification summaries and provenance links. Implementation source, binaries, detailed coverage and conversation archives retain their private access requirements.

The static site is generated from Markdown. Each assignment row links directly to named test-result anchors, the relevant source lines at the verified revision and original GitHub Actions artifact bundles. Manual questions and reviewer-sharing actions remain explicitly pending.

The `public/verification.json` file identifies the source revision. Every published file is included in `public/SHA256SUMS`. The Pages workflow verifies that manifest, uploads the site archive and deploys it using GitHub Pages OIDC. Website code is generated; changes belong in the private source repository.
